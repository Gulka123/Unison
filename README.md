## Возможности

- **Моя волна** — бесконечный умный автомикс на основе вашей коллекции и похожих исполнителей.
- **Единый поиск и профили артистов** — треки, популярные релизы, альбомы и похожие артисты.
- **Плейлисты и «Любимое»** — синхронизация плейлистов из подключённых аккаунтов (Яндекс Музыка, SoundCloud, Spotify), импорт по ссылке, обновление в 1 клик, экспорт в JSON и M3U8.
- **Офлайн-загрузки** — скачивание отдельных треков и целых плейлистов на устройство с кэшированием обложек и приоритетным воспроизведением без интернета.
- **Три темы оформления** — Яндекс Музыка, Spotify и SoundCloud.
- **Полноценный ПК-клиент (Windows):**
  - адаптивная боковая панель на широком экране и десктопный плеер с громкостью и перемоткой;
  - системный трей и интеграция с системной медиа-панелью Windows 10/11 (SMTC, аппаратные медиа-клавиши);
  - горячие клавиши (`Space` — пауза/плей, `Ctrl+Left/Right` — пред./след. трек, `Ctrl+F` — поиск) и контекстное меню по ПКМ;
  - встроенная авторизация через Edge WebView2 с резервным входом через браузер.
- **Безопасность:** токены аккаунтов шифруются средствами ОС (`Windows DPAPI` на ПК, `Android Keystore AES-256-GCM` на телефоне).

## Установка (v0.4.2)

Скачайте нужный файл со страницы [**Releases**](https://github.com/Gulka123/Unison/releases/latest):

### Windows (x64)
1. Скачайте **`Unison-win-x64-v0.4.2.zip`**.
2. Распакуйте архив целиком в удобную папку и запустите **`Unison.exe`**.
3. *Примечание:* при первом запуске Windows SmartScreen может показать предупреждение о неизвестном издателе (приложение не подписано платным EV-сертификатом) — нажмите **«Подробнее → Выполнить в любом случае»**.

### Android
1. Скачайте **`Unison-android-v0.4.2.apk`**.
2. Установите APK на устройство (Android 6.0+, может потребоваться разрешение установки из неизвестных источников).
